# FLUJO DE PRODUCCIÓN — CAT CODE

**Versión:** 2026-09-10 · **Único flujo operativo.** 17 pasos, desde el primer contacto hasta la publicación.

---

## Los 17 pasos

| # | Paso | Responsable | Comentario |
|---|---|---|---|
| 1 | **Contacto inicial** | CEO | WhatsApp / formulario web / referido. Frase default de WhatsApp en COPY_CTA.md |
| 2 | **Necesidades (mini-discovery)** | CEO | Qué quiere el cliente, qué tiene hoy, presupuesto |
| 3 | **Propuesta (`PROP-…`)** | CEO | Ver 08_PLANTILLAS/PROPUESTA |
| 4 | **Negociación / cierre** | CEO | Precios sin descuentos informales (Reglas comerciales) |
| 5 | **Onboarding** | CEO + Cliente | Ver 08_PLANTILLAS/ONBOARDING. A partir de aquí se abre la carpeta del cliente |
| 6 | **Setup de cuenta(s)** | CEO | Correo, redes (Facebook/Instagram), usuario, contraseñas seguras |
| 7 | **Repositorio y control de código fuente (GitHub)** | CEO/Backend/Frontend | Org Cat-CODE-Hdz · rama por versión · tag `_FINAL` tras aprobación · sin secretos |
| 8 | **Copia + Branding** | Frontend/Social | Recolectar colores, logo, textos, fotos. STOP aquí para diseño |
| 9 | **Diseño landing + contenido** | Backend/CEO + Frontend/Social | Según nivel CUSTOM/WEEKLY/SOCIAL; ver SECCIONES_LANDING.md |
| 10 | **Revisión interna** | Equipo (Backend · Frontend · Social) | QA global antes de verse con el cliente (ver 08_PLANTILLAS/QA) |
| 11 | **Aprobación del cliente** | Cliente | Firma "APROBADO" (landing 72h / weekly 48h) |
| 12 | **Ajustes post-aprobación** | Frontend/Social | Solo lo pactado en el cambio |
| 13 | **Publicación** | Equipo/Social | Responsable según nivel: ver PUBLICACION.md |
| 14 | **Entrega** | CEO | Entrega de accesos, link, informe 1º sencillo |
| 15 | **Seguimiento (check-in)** | CEO + Frontend | Revisión mensual de resultados |
| 16 | **Actualización/mantenimiento** | Equipo | Contenido semanal / landing actualizada |
| 17 | **Renovación o cierre** | CEO | Continúa o se cierra tras aviso. Ver REGLAS_SERVICIOS |

## Estados de un proyecto

1. `PROSPECTO` (contacto)
2. `PROPUESTA` (propuesta enviada)
3. `GANADO` (cierre)
4. `ONBOARDING`
5. `EN_DISENO`
6. `EN_REVISION`
7. `APROBADO`
8. `PUBLICADO`
9. `EN_SEGUIMIENTO`
10. `CERRADO`

## Reglas

- Nunca se publica nada sin pasar por el paso 11 (APROBADO).
- Un cambio tras "APROBADO" se registra y se trata como cambio de alcance si supera lo pactado.
- Cada proyecto se almacena en `04_CLIENTES/` con la nomenclatura definida en DOCUMENTO 16: `CCXXX_…`.
