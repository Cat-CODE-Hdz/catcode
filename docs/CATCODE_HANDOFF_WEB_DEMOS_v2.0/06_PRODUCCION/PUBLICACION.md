# PUBLICACIÓN — QUIÉN, CUÁNDO Y CÓMO

**Parte del flujo de producción (paso 13).** Define quién publica según el nivel contratado.

---

## Quién publica

| Nivel | Publicación | Detalle |
|---|---|---|
| **WEEKLY BASIC** | El equipo crea, el **cliente publica** | Se entrega el contenido y el calendario; el cliente lo sube |
| **WEEKLY PRO / PREMIUM** | **CAT CODE publica** | Equipo sube a Facebook + Instagram con la cuenta configurada |
| **SOCIAL (cualquier nivel)** | **CAT CODE publica** | Es la razón del servicio: publicación gestionada |
| **FULL** | **CAT CODE publica** | Todo integrado (Custom + Weekly + Social) |

## Cuándo se publica

- Contenido Weekly: según el calendario semanal (ver ESTRUCTURA_CARPETA_SEMANAL.md).
- Días tipo por formato (acordar con el cliente en onboarding):
  - Lunes Promoción / Martes Consejo / Miércoles Inspiración / Jueves Prueba Social / Viernes Interacción.
- Horario recomendado: según datos de cada cuenta (si el nivel lo permite), por defecto 09:00–13:00 y 18:00–21:00.
- Landing: al aprobarse (APROBADO → publicar en 24h salvo indicación).

## Cómo se publica (checklist)

1. [ ] Contenido aprobado ("APROBADO") y en `_FINAL`.
2. [ ] Cuenta configurada (correo, acceso, seguridad).
3. [ ] Copia + pieza gráfica correctos y sin error.
4. [ ] Publicar en el canal correspondiente (FB + IG).
5. [ ] Verificar visualización en móvil y horario.
6. [ ] Si el cliente publica (WEEKLY BASIC), se le entrega guía de publicación y plantilla de calendario.

## Errores comunes

- Publicar sin aprobación → violación del flujo (APROBACION.md).
- Publicar en cuenta equivocada / sin permiso.
- Publicar fuera del horario pactado.
- No verificar en móvil.

## Registro

- Cada publicación se anota en `00_REGISTRO/` carpeta tipo `REPARTO_YYYY-MM.md` o bitácora del cliente según convención (ver ESTRUCTURA_CARPETA_SEMANAL.md).
