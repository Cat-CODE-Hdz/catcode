# 17. REGLA CLAVE PARA GENERARLAS

No generes cada imagen de forma independiente cambiando completamente el estilo.

Primero genera:

**1. Hero → 2. Taller → 3. Servicios → 4. Ubicación**

y utiliza las imágenes aprobadas como **referencia visual** para las siguientes generaciones cuando la herramienta de IA lo permita.

Así conseguiremos que:

> **el mismo banco de trabajo aparezca en todas las fotografías, el mismo grafito y el mismo naranja marquen los detalles, y Taller Recambios tenga una identidad visual coherente.**

Eso hará una diferencia enorme entre una demo que parece un conjunto de imágenes IA y una demo que **parece una marca real**.
