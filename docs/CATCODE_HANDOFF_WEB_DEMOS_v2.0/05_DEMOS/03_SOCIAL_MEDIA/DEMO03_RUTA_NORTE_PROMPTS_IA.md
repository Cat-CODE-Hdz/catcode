### Recomendación clave para la IA

Para que el resultado sea **realmente consistente**, genera primero **Hero + Featured + About**. Después usa esas imágenes como **referencia visual** al generar las restantes. Así las personas, iluminación, tratamiento de color y estética parecerán pertenecer a una misma campaña fotográfica.

Y en todas las imágenes evita texto generado por IA: **los títulos, etiquetas, nombres de destinos y CTA los pondrá OpenCode/HTML**, no el generador de imágenes.
