## Orden recomendado de generación

Para mantener **consistencia visual**, genera primero:

**01 Hero → 02 Interior → 03 Profesional → 04 Modelo → 05 Servicios**

Después utiliza esas imágenes como **referencias visuales** en la IA para generar las demás.

Especialmente importante: la modelo del Hero y las fotografías de resultados deberían parecer parte de **la misma sesión fotográfica**, con la misma piel, cabello, iluminación y dirección artística.

Así Estudio Lumen podrá mostrar exactamente lo que debe demostrar el paquete **SOCIAL**: **contenido visual profesional + presencia social + una web que convierte ese contenido en reservas**, en lugar de parecer simplemente una landing bonita.
