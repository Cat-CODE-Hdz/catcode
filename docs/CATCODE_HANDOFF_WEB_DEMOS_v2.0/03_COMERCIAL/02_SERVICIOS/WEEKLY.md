## Qué es

Contenido semanal para redes sociales (Facebook + Instagram): 3, 5 o 7 piezas por semana según nivel, listas para publicar. El negocio no escribe nada; nosotros redactamos y diseñamos.

## Formato semanal (5 piezas = nivel Pro; Basic 3 · Premium 7)

| Día | Tipo | Archivo plantilla |
|---|---|---|
| Lunes | Promoción | `05_COPY/COPY_PROMOCION.md` |
| Martes | Consejo | `05_COPY/COPY_CONSEJO.md` |
| Miércoles | Inspiración | `05_COPY/COPY_INSPIRACION.md` |
| Jueves | Prueba social | `05_COPY/COPY_PRUEBA_SOCIAL.md` |
| Viernes | Interacción | `05_COPY/COPY_INTERACCION.md` |

## Reglas de contenido
- Copy 5 elementos: **Hook → Contexto → Beneficio → Información → CTA** (ver `05_COPY/ESTRUCTURA_COPY.md`).
- Se respeta el tono y los mensajes de marca (ver `04_MARCA/`).
- Toda pieza se guarda en la carpeta semanal del cliente (`CCXXX_CLIENTE_SEMANA_YYYY-MM-DD`).
- Prohibido reutilizar la misma pieza en dos semanas seguidas (variar siempre).
