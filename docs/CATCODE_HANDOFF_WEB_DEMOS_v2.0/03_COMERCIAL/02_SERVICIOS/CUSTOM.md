# CUSTOM — Tu landing

**Service ID:** `CUSTOM`
**Niveles:** Basic / Pro / Premium (`CUSTOM_BASIC`, `CUSTOM_PRO`, `CUSTOM_PREMIUM`)
**Precios:** ver `01_COMERCIAL/PRECIOS.md`

---

## Qué es

Tu página web de una sola página (landing) donde el negocio se presenta, comunica su oferta y capta contacto. Es la puerta de entrada de la presencia digital.

## Qué incluye (por nivel)

### Custom Basic — €149 + €19/mes
| Incluye |
|---|
| Landing de 5 secciones (hero con CTA WhatsApp, sobre nosotros, servicios, confianza, ubicación) |
| Hosting incluido |
| Diseño con los colores del negocio, responsive y SEO básico |
| Entrega en 48–72 h · 1 ronda de cambios |

**No incluye:** galería, testimonios y FAQ (Pro), blog y casos de éxito (Premium), funcionalidades extra, soporte prioritario.

## Flujo de entrega
1. Onboarding clientes → 2. Propuesta + firma → 3. Diseño/copy → 4. Maquetación → 5. Revisión 72h → 6. Publicación → 7. **APROBADO** → 8. Entrega + cierre.

## Colabora con
- **WEEKLY**: mismo tono de marca, el contenido social enlaza a la landing.
- **SOCIAL**: la landing recibe tráfico de las publicaciones.
- **FULL**: bundle completo con descuento implícito (ver FULL).
