# REGLAS COMERCIALES — CAT CODE

**Propósito:** reglas operativas que gobiernan ventas, cotización, onboarding y cobro. Aprobación de cambios: CEO.

---

## 1. Canales de venta

| Canal | Acción |
|---|---|
| WhatsApp | Mensaje prellenado: *Hola CAT CODE, quiero mejorar la presencia digital de mi negocio.* |
| Web `/contacto` | Formulario "Cuéntanos qué necesita tu negocio." → llega a contacto interno |
| Referidos | Comisión/reconocimiento según acuerdos vigentes |

## 2. Propuesta comercial

- Toda propuesta usa la plantilla `08_PLANTILLAS/PROPUESTA/PROPUESTA_COMERCIAL.md`.
- Número de propuesta: `PROP-YYYY-MM-NN` (año-mes-secuencia).
- Código de cliente: `CCXXX_NOMBRE` (ej.: `CC001_CAFETERIA_LA_ESQUINA`).
- Toda propuesta incluye: alcance, nivel elegido, precio, plazos, condiciones de cobro y firma.

## 3. Onboarding

- Al cerrar venta se envía el formulario de onboarding (`08_PLANTILLAS/ONBOARDING/FORMULARIO_ONBOARDING.md`).
- Se abre la carpeta del cliente según `06_PRODUCCION/ESTRUCTURA_CARPETA_SEMANAL.md`.
- El proyecto se crea bajo `UNIFICADO/` + una carpeta de proyecto real (en el entorno de trabajo del cliente).

## 4. Facturación y cobro

| Cargo | Cuándo |
|---|---|
| Setup (solo CUSTOM) | Antes de iniciar diseño |
| Mensualidad | El 1 de cada mes por adelantado |
| Cambio de nivel | Al siguiente ciclo (baja) o prorrateado (subida) |

- Impagos: se pausa la publicación y el soporte hasta regularizar. Sin permanencias, pero se avisa.

## 5. Renombrado de servicios (norma vigente desde 2026-09-10)

- **Reemplaza** los nombres antiguos del OS v1: `START → CUSTOM_BASIC`, `BUSINESS → CUSTOM_PRO`, `PRO → CUSTOM_PREMIUM`.
- En documentos, plantillas y web se usan SIEMPRE los nombres nuevos con sufijo.
- Los nombres antiguos en documentos archivados NO se modifican (histórico intacto).

## 6. Regla de oro de propiedad

Todo lo que se crea para CAT CODE pertenece a CAT CODE: cuentas de la empresa, plantillas, contenido, repositorios. Recuperable sin depender de una persona.

## 7. Matriz de aprobación interna

| Acción | Quién aprueba |
|---|---|
| Precios, ofertas y descuentos | CEO |
| Nivel/escalación de cliente | CEO |
| Cambios de identidad de marca | CEO |
| Publicación (si aplica) | Cliente o equipo según aprobación configurada |
| Incorporación de socio/reparto | CEO + Inversor |
