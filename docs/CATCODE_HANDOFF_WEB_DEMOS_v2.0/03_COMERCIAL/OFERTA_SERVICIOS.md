# OFERTA DE SERVICIOS — CAT CODE

**Descriptor de marca:** *Landing + contenido + publicación. Sin complicaciones.*

**Misión operativa:** CAT CODE construye la presencia digital de pequeños negocios: una landing page profesional, contenido semanal para redes y publicación automática. Todo conectado, sin que el negocio tenga que montar nada.

---

## Catálogo de servicios

| Servicio | Qué es | Para quién |
|---|---|---|
| **CUSTOM** · *Tu landing* | Página web de una sola página (landing) | Negocios que necesitan presencia web profesional |
| **WEEKLY** · *Tu contenido* | 3 a 7 piezas de contenido social semanales (FB + IG), según nivel | Negocios que quieren contenido constante sin escribirlo ellos |
| **SOCIAL** · *Tus redes* | Publicación + presencia en Facebook e Instagram | Negocios que quieren estar activos sin gestionar las redes |
| **FULL** · *Todo conectado* | Landing + contenido + publicación, todo integrado | Negocios que quieren la presencia digital completa |

---

## Niveles

Todos los servicios y productos usan el mismo sistema de niveles con sufijo.

| Nivel | Sufijo en archivos/nombres |
|---|---|
| Básico | `_Basic` |
| Pro | `_Pro` |
| Premium | `_Premium` |

Regla: un producto con niveles siempre se nombra como `SERVICIO_NIVEL` (ej.: `CUSTOM_PRO`, `WEEKLY_PREMIUM`).

## Garantía de servicio

- **Sin permanencias:** contratos flexibles; se puede pausar o cambiar de nivel.
- **Sin complicaciones:** el equipo de CAT CODE se encarga del contenido y la publicación.
- **Aprobación antes de publicar:** el cliente aprueba (o solo el equipo lo aprueba según nivel).
- **Entrega transparente:** toda entrega se documenta y se registra en la carpeta del proyecto.
