## Estructura de copy por sección

- **Hero:** H1 + 1 línea sub + 1 CTA. Nada más.
- **Servicios:** tarjeta por servicio: título, 1 frase de valor, precio desde.
- **Precios:** tabla data-driven (plans.ts), badges "MÁS ELEGIDO" / "RECOMENDADO".
- **FAQ:** pregunta → 1 respuesta corta (<60 palabras), link a precios/contacto si aplica.
- **Formulario /contacto:** labels claros, mensaje de éxito/error definidos (ver CONTACTO_WEB.md).

## Reglas generales

1. Español latino, sin tecnicismos innecesarios.
2. Sin promesas de resultados ("garantizado") que no se cumplan.
3. CTA en imperativo y único por sección.
4. Sin permanencias: mencionar como diferenciador (FAQ).
5. Nombres de planes SIEMPRE con los nuevos nombres (CUSTOM/WEEKLY/SOCIAL/FULL, Basic/Pro/Premium).
